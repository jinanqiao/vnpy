# Feature Specification: 主线强势股选股信号（行业筛选 + 个股打分）

**Feature Branch**: `001-mainline-trend-strategy`

**Created**: 2026-07-08（2026-07-08 修订：范围收窄至信号生成层，回测与风控另行立项）

**Status**: Draft

**Input**: User description: "基于做法A（先选行业、后选股的漏斗式结构），梳理行业选择与选股策略：用到哪些必要因子、信号生成条件是什么、因子如何组合。回测与风控本次不涉及。"

## 范围说明

本规格只覆盖**信号生成层**：给定一个月末调仓日，系统如何从全市场走到一份"主线行业 + 入选个股"清单。共两层漏斗：

1. **行业层**：从全部行业中选出当期主线行业（2 个因子：动量定强弱、广度验真伪）；
2. **个股层**：在主线行业内过滤并打分，选出入选个股（3 个打分因子 + 2 个过滤因子）。

**本次不涉及**：回测引擎、交易成本、大盘仓位风控、主线切换换出规则、绩效报告与稳健性体检。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 选出当期主线行业 (Priority: P1)

研究员指定一个月末调仓日，系统计算全部行业的动量并排名，经双窗口确认与上涨广度确认后选出主线行业，输出每个行业的动量值、排名、广度值和是否入选，全程留档可查。

**Why this priority**: 行业选择是漏斗第一层，决定后续选股范围；结构性行情的收益主要来自押中主线，这一层单独就有研究价值。

**Independent Test**: 对最近一个月末运行，人工核对选出的主线行业与当期市场热点是否相符。

**Acceptance Scenarios**:

1. **Given** 全 A 日线与行业成分数据就绪，**When** 对某调仓日运行行业筛选，**Then** 输出全部行业的 60 日/20 日动量值、两组排名、上涨广度值及入选标记。
2. **Given** 某行业 60 日动量排名第 3、20 日动量排名第 10，**When** 双窗口确认执行，**Then** 该行业不入选（20 日排名未进门槛）。
3. **Given** 某行业双窗口动量排名均进门槛但上涨广度只有 45%，**When** 广度确认执行，**Then** 该行业不入选，留档原因记录为"广度不足（疑似权重股独涨的伪主线）"。
4. **Given** 满足全部入选条件的行业只有 3 个，**When** 主线筛选执行，**Then** 只选出 3 个主线行业，不硬凑到 5 个。

---

### User Story 2 - 主线行业内选出强势个股 (Priority: P1)

研究员在已确定主线行业的前提下运行选股：系统先对行业内个股执行硬过滤（不合格直接剔除并记录原因），再对存活个股计算三个打分因子、合成总分，按行业内排名输出入选个股清单。

**Why this priority**: 与行业筛选共同构成完整信号，两者合起来才是可交付的最小闭环。

**Independent Test**: 取某个调仓日的输出，抽查得分前 10 的个股 K 线，应全部呈现"均线向上发散、接近一年新高"的强势形态；抽查任一被剔除个股，留档中应有明确剔除原因。

**Acceptance Scenarios**:

1. **Given** 某股票收盘价高出其 20 日均线 30%，**When** 过滤执行，**Then** 该股票被剔除，剔除原因记录为"乖离率过热"。
2. **Given** 某股票三项因子原始值已算出，**When** 打分执行，**Then** 总分等于三项因子行业内百分位排名按 40%/35%/25% 的加权和。
3. **Given** 某主线行业过滤后只剩 4 只合格个股，**When** 选股执行，**Then** 该行业入选 4 只，不硬凑到 6 只。
4. **Given** 相同输入数据与参数，**When** 重复运行，**Then** 输出完全一致（可复现）。

---

### Edge Cases

- 调仓日之前历史数据不足 252 日的个股（52 周新高窗口无法完整计算）：直接不参与选股，不允许用短窗口近似。
- 满足双窗口确认与广度确认的行业为 0 个：当期输出空清单并记录原因，不放松入选门槛。
- 个股无行业归属（行业成分数据缺失）：不参与行业动量计算，也不进入选股范围，记入数据质量日志。
- 某行业成分股不足以计算有意义的行业动量（如少于 5 只）：该行业不参与行业排名，记录原因。
- 三项打分因子中任一项因数据缺失无法计算的个股：直接剔除并记录原因，不允许用默认值补位。

## Requirements *(mandatory)*

### 第一层：行业选择

**因子 1：行业动量（IND_MOM）——主因子，定强弱**

- **FR-001**: 系统必须以行业内成分股**等权日收益**复合构建行业净值，并据此计算每个行业的动量：`IND_MOM_60 = 行业净值(t) / 行业净值(t-60) - 1`，同式另算 20 日窗口。

**因子 2：行业上涨广度（IND_BREADTH）——确认因子，验真伪**

- **FR-002**: 系统必须计算每个行业的上涨广度：`IND_BREADTH_60 = 行业内过去 60 日累计收益为正的成分股数量 / 行业成分股总数`。目的：区分"资金全面进驻的真主线"（普涨、广度高）与"一两只权重股独涨拉起行业指数的伪主线"（广度低）；该信息与动量重叠度低，动量衡量涨多少、广度衡量多少股票在涨。
- **FR-003**: 主线行业的**信号生成条件**：① 60 日动量排名与 20 日动量排名**同时进入排名门槛**（双窗口确认，防止追到已经衰竭的行业或刚冒头的假热点）；② 上涨广度 `IND_BREADTH_60 ≥ 60%`（广度确认，阈值可配置）。在同时满足者中按 60 日动量取**前 N 名**；满足者不足 N 个时按实际数量选取，为 0 时当期空清单。门槛与 N 随行业总数校准：数据湖实际为 11 个 GICS 一级行业，默认**门槛前 5、主线前 3**（若未来行业分类扩展到约 30 个，对应门槛前 8、主线前 5）。

### 第二层：个股过滤（先过滤，后打分；任一不满足即剔除并记录原因）

**因子 3：均线多头排列（MA_ALIGN）——趋势结构过滤**

- **FR-004**: 剔除条件：不满足"20 日均线 > 60 日均线 > 120 日均线，且 20 日均线高于其 5 个交易日前的值"。目的：只保留趋势结构完好且仍在向上的个股。

**因子 4：乖离率（BIAS_20）——过热过滤**

- **FR-005**: 剔除条件：`收盘价 / 20日均线 - 1 > 25%`。目的：顺势不追情绪顶点，回避短期涨幅过陡、大概率回调的个股。

**基础可交易性过滤**

- **FR-006**: 调仓日必须处于可交易股票池：非停牌、非一字涨停、非 ST、上市满 252 日（保证全部因子窗口可完整计算）。

### 第二层：个股打分（对过滤后存活的个股计算，行业内合成）

**因子 5：相对强度（RS_60）——权重 40%**

- **FR-007**: 计算：`个股 60 日累计收益 - 所属行业 60 日累计收益`。方向：越大越好。目的：剥离行业 beta，找出行业内资金真正聚焦的领涨个股，权重最高。

**因子 6：距 52 周新高（NH_252）——权重 35%**

- **FR-008**: 计算：`当日收盘价 / 过去 252 日最高价`，取值 (0, 1]。方向：越接近 1 越好。同时兼做过滤：`NH_252 < 0.80` 直接剔除（离高点太远视为趋势结构已破坏）。

**因子 7：量价配合（VOL_RATIO）——权重 25%**

- **FR-009**: 计算：`20 日日均成交额 / 60 日日均成交额`，结果大于 3 的截断为 3（防止把游资爆炒股排到最前）。计入条件：仅当该个股近 20 日累计收益为正时按实际值计分（放量上涨才是确认），否则该项按中位数 0.5 计（放量下跌视为出货，不给放量加分）。

**因子组合方式**

- **FR-010**: 三项打分因子在**主线行业候选池内**（过滤后存活个股）分别做百分位排名（0~1），按固定权重线性加权：`总分 = 0.40 × rank(RS_60) + 0.35 × rank(NH_252) + 0.25 × rank(VOL_RATIO)`。权重必须可配置，且支持三项等权的对照配置。
- **FR-011**: 入选规则：每个主线行业按总分取**前 6~10 只**（具体数量可配置），全组合目标 30~50 只；行业内合格个股不足下限时按实际数量纳入，不硬凑、不跨行业借调。

### 通用要求

- **FR-012**: 信号计算严禁使用调仓日收盘之后的任何数据（无未来函数）；所有窗口均以调仓日为右端点向前取数。
- **FR-013**: 全部参数（窗口 60/20/252、行业门槛 5 与主线数量 3、广度阈值 60%、乖离率上限 25%、新高下限 0.80、权重 40/35/25、每行业 6~10 只）必须集中可配置，运行时参数快照随结果留档。
- **FR-014**: 中间结果必须完整留档：行业动量、广度与排名、每只个股的三项因子原始值与百分位排名、总分、各过滤项通过情况、剔除原因。

### Key Entities

- **行业信号快照**: 调仓日 × 行业：60/20 日动量值、两组排名、上涨广度值、是否入选主线及未入选原因。
- **个股信号快照**: 调仓日 × 个股：三项因子原始值、行业内百分位排名、总分、各过滤项结果、剔除原因（如有）。
- **入选清单**: 调仓日、股票代码、所属主线行业、总分、行业内名次。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 对任意指定的历史月末调仓日，一条命令产出该期"主线行业 + 入选个股"清单及全部中间留档，无需人工干预。
- **SC-002**: 抽查任意三个调仓日：入选个股 100% 通过全部过滤条件，每行业数量在 6~10 只区间内（或有留档的不足例外），无重复。
- **SC-003**: 抽查任一被剔除个股，留档中可查到唯一明确的剔除原因；抽查任一入选个股，可查到三项因子的原始值与排名，人工复算总分误差为 0。
- **SC-004**: 相同输入与参数重复运行两次，输出逐字节一致。
- **SC-005**: 最近一个调仓日选出的主线行业，与该时点市场公认热点方向一致（人工评审通过）。

## Assumptions

- 数据基础：使用项目数据湖现有的全 A 日线行情（默认股票池）、行业成分、分层可交易股票池数据；不新增外部数据源。龙头池（沪深300+中证500）作为可配置备选，本次仅要求股票池参数可切换，不要求对比分析。
- 行业分类：使用数据湖中现有行业成分数据；若为当前时点快照而非逐日历史成分，接受由此产生的偏差并在结果说明中明示。
- 调仓日定义：每月最后一个交易日，以交易日历数据为准；本规格只负责"算出该日的信号"，信号如何被执行（次月成交）属于回测/执行层，不在本次范围。
- 上市满 252 日的门槛同时满足了 52 周新高与 120 日均线两个最长窗口的计算需要。
- 全部参数默认值为经验起点值而非调优结果，后续由回测阶段的参数敏感性分析检验。
- 本策略仅用于研究与学习，不构成投资建议。
