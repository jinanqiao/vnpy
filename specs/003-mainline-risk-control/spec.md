# Feature Specification: 主线策略风控层

**Feature Branch**: `003-mainline-risk-control`

**Created**: 2026-07-09

**Status**: Draft

**Input**: User description: "策略风控没做。给回测加风控层：大盘择时开关、无信号月清仓、个股月中止损，做成可开关的参数，然后跑对照回测验证真实效果。"

## 背景

002 特性的全历史回测给出了如实的答案：策略总收益 -31.4%（基准 +14.9%），最大回撤 -52.8%。归因分析显示亏损高度集中在"大盘走弱"的时段——沪深300 在自身 60 日均线上方的 487 个交易日里组合累计 +36%，下方的 402 个交易日里累计 -31%。此外 45 个月中有 17 个月信号层选不出主线行业（市场没有主线），但旧持仓被动保留继续亏损。

本特性给回测加一个**风控层**：在既有的"信号 → 执行"链路上插入三个独立可开关的风控规则（大盘择时、无信号清仓、个股止损），并通过对照回测量化每条规则的真实贡献。风控只减仓、不加仓、不改选股——信号层（001）与执行层（002）的既有语义保持不变。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 大盘择时开关：弱市空仓 (Priority: P1)

研究者打开"大盘择时"开关重跑回测：每个调仓执行日，若沪深300 收盘价（截至执行日前一交易日，无未来信息）低于其 60 日均线，则该期不买入任何新股票，并卖出全部现有持仓、全额持有现金；直到某个后续调仓日大盘重新站上均线才恢复正常调仓。研究者对比开关前后的净值曲线与回撤，判断择时的真实价值。

**Why this priority**: 归因数据显示这是最大的亏损来源，是三条规则中预期贡献最大的一条。

**Independent Test**: 用合成数据构造"基准跌破均线"的时段，验证该时段组合空仓、净值平直；用真实数据对比开关前后指标。

**Acceptance Scenarios**:

1. **Given** 某调仓执行日前一交易日基准收盘 < 60 日均线，**When** 回测处理该期，**Then** 不执行任何买入，现有持仓全部卖出（正常计成本），组合转为全现金
2. **Given** 择时空仓期间，**When** 逐日估值，**Then** 净值平直（现金无息），持仓明细为空
3. **Given** 后续某调仓日基准重新站上均线，**When** 回测处理该期，**Then** 按当期信号正常等权买入
4. **Given** 均线计算，**When** 检查所用数据，**Then** 只使用执行日之前（不含执行日）的基准收盘价，无未来信息
5. **Given** 择时开关关闭，**When** 重跑回测，**Then** 结果与 002 现状逐字节一致（回归保护）

---

### User Story 2 - 无信号月清仓 (Priority: P1)

研究者打开"无信号清仓"开关：信号层在某个月末选不出任何主线行业时（该月无 selection 记录），下月首个交易日卖出全部持仓转为现金，而不是被动保留旧持仓。信号层说"市场没有主线"，仓位应当服从这个判断。

**Why this priority**: 归因显示无信号月被动持仓额外亏损约 -3.4%；实现简单、语义清晰，与 US1 同为纯减仓规则。

**Independent Test**: 合成数据构造一个"有信号月 → 无信号月 → 有信号月"序列，验证中间月清仓、净值平直、随后正常恢复。

**Acceptance Scenarios**:

1. **Given** 某月末信号清单为空且持仓非空，**When** 开关打开，**Then** 次月首个交易日按正常卖出规则清仓（停牌顺延照旧），清仓交易记录标注来源为"无信号清仓"
2. **Given** 开关关闭，**When** 遇到无信号月，**Then** 行为与 002 现状一致（继续持有旧仓）
3. **Given** 连续多个无信号月，**When** 回测经过，**Then** 只在第一个无信号月清仓一次，其后保持空仓

---

### User Story 3 - 个股月中止损 (Priority: P2)

研究者打开"个股止损"开关并设定阈值（默认 15%）：持仓期间任一交易日收盘价较买入执行价（后复权口径）下跌超过阈值时，于次一交易日开盘卖出该股（停牌/一字跌停顺延，与 002 卖出规则一致），腾出的资金留存现金直到下一调仓期。

**Why this priority**: 单票深度回撤的兜底保护；但月度轮动本身持有期短，预期贡献小于前两条，且引入盘中路径依赖，放在 P2。

**Independent Test**: 合成数据构造一只"买入后单边下跌 20%"的股票，验证在跌破 15% 的次日被卖出并记录止损原因；未触发止损的股票不受影响。

**Acceptance Scenarios**:

1. **Given** 某持仓收盘价较买入执行价回撤首次超过阈值，**When** 次一交易日可交易，**Then** 开盘卖出，交易记录标注"止损"及触发日期
2. **Given** 止损触发但次日停牌/一字跌停，**When** 回测处理，**Then** 顺延到下一个可交易日卖出（沿用 002 延迟卖出机制）
3. **Given** 止损卖出后同一只股票再次入选下一期信号，**When** 下一调仓日到来，**Then** 正常按新信号买入（止损不拉黑）
4. **Given** 开关关闭，**When** 重跑回测，**Then** 结果与 002 现状一致

---

### User Story 4 - 风控对照实验报告 (Priority: P1)

研究者一次性跑出四组对照回测——无风控基线、仅择时、择时+无信号清仓、三条全开——对比总收益、最大回撤、夏普、换手率的变化，量化每条风控规则的边际贡献，回答"做完风控整体是不是更好"。

**Why this priority**: 这是本特性的最终交付物——不是"加了风控"，而是"风控值多少"的量化答案。

**Independent Test**: 四组真实数据回测全部完成，产出一张对照表，每组的配置快照能反映各自开关状态。

**Acceptance Scenarios**:

1. **Given** 四组不同开关组合的回测，**When** 对比产物，**Then** 每组 config 快照准确记录开关状态与参数，指标差异可归因到具体规则
2. **Given** 对照结果，**When** 查看汇总报告，**Then** 能看到每条规则对总收益/最大回撤/换手率的边际影响
3. **Given** 全部开关关闭的基线组，**When** 与 002 的历史产物对比，**Then** 指标完全一致

---

### Edge Cases

- 回测起点处均线窗口不足 60 个交易日：择时视为"通过"（不空仓），并在数据质量日志记录窗口不足的时段
- 择时空仓期间持仓中有停牌股卖不出：沿用 002 延迟卖出机制，可卖部分先卖，停牌部分挂起补卖
- 择时空仓与无信号月同时发生：效果相同（清仓），清仓交易只记录一次，原因标注优先级：择时 > 无信号
- 止损触发日恰逢调仓执行日：调仓卖出优先（全卖全买语义已覆盖），不重复卖出
- 止损阈值设为极端值（如 1%）：允许，高换手是研究者自己的选择；阈值 ≤ 0 视为配置错误直接报错
- 基准行情缺失某些交易日：均线用可得数据顺延计算（与 002 基准对齐逻辑一致）
- 择时导致某期放弃的买入：不记为 abandoned 交易（该期根本没有买入计划），在数据质量日志记录"择时跳过该期"

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 三条风控规则 MUST 各自独立可开关、可配置参数（择时均线窗口默认 60、止损阈值默认 15%），全部默认关闭——默认行为与 002 完全一致
- **FR-002**: 大盘择时 MUST 只使用执行日之前（不含当日）的基准收盘价计算均线，无未来信息
- **FR-003**: 择时判定为"弱市"的调仓期 MUST 跳过全部买入并清仓现有持仓；卖出沿用 002 的执行规则（开盘价、滑点、成本、停牌顺延）
- **FR-004**: 无信号清仓 MUST 在信号清单无该月记录且开关打开时，于该月末的次一交易日清仓；连续无信号月只清仓一次
- **FR-005**: 个股止损 MUST 以"收盘价较买入执行价（后复权口径）的回撤"为触发条件，触发后次一交易日开盘卖出，复用 002 的卖出受阻顺延机制
- **FR-006**: 风控触发的每笔卖出 MUST 在交易流水中标注触发来源（择时清仓 / 无信号清仓 / 止损），与调仓卖出可区分
- **FR-007**: 风控层 MUST 只做减仓动作：不加仓、不改变信号层的选股与权重语义、不在空仓期主动建仓
- **FR-008**: 全部开关关闭时回测结果 MUST 与 002 现状逐字节一致（回归保护）
- **FR-009**: 系统 MUST 支持一次性跑出多组开关组合的对照回测并汇总为对照表（至少覆盖：基线 / 仅择时 / 择时+清仓 / 全开 四组）
- **FR-010**: 风控参数与开关状态 MUST 完整记录在每次运行的配置快照中；择时跳过的调仓期、窗口不足时段记入数据质量日志
- **FR-011**: 既有产物契约（六件套、八条不变式）MUST 全部继续成立，交易状态/原因枚举按需扩展且保持封闭

### Key Entities

- **风控配置**: 三个开关与各自参数（均线窗口、止损阈值），并入既有回测配置快照
- **风控触发记录**: 每次择时空仓/无信号清仓/止损的触发日期、原因、涉及持仓，体现在交易流水的来源标注与数据质量日志
- **对照实验汇总**: 多组运行的开关状态 + 核心指标对照表

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 全部开关关闭时，回测数值产物与 002 基线逐字节一致
- **SC-002**: 打开大盘择时后，全历史回测最大回撤比基线收窄（预期从 -52.8% 显著改善），弱市时段组合持币
- **SC-003**: 四组对照回测一次性完成（总耗时 ≤ 5 分钟），对照表呈现每条规则对收益/回撤/换手的边际影响
- **SC-004**: 任意一笔风控卖出可追溯触发来源与触发日期，与普通调仓卖出可区分
- **SC-005**: 同输入重跑，全部数值产物逐字节一致（可复现性延续）
- **SC-006**: 非专业读者能从汇总报告在 5 分钟内看懂"每条风控规则值多少"

## Assumptions

- 择时基准沿用沪深300（002 已接入），均线窗口默认 60 个交易日（与归因分析口径一致），窗口可配置
- 择时判定只发生在调仓执行日（月度粒度），月中不做择时干预——避免高频进出与均线附近的反复磨损；这意味着实际效果会低于事后逐日模拟的 +36%，属于如实呈现
- 择时空仓期间错过的月份信号不补买：直到下一个"大盘站上均线"的调仓日才用当期新信号建仓
- 止损基准价 = 买入执行价（含滑点的实际成交口径，后复权演化），非当期最高价（不做移动止损，留待后续）
- 止损后资金留存现金至下一调仓期，不做月中再投资
- 风控层在既有回测子包内实现（新增参数与规则模块），不新建独立子包；代码风格约束沿用 001/002（自包含、函数式、中文注释、单文件 ≤ 300 行），具体在 plan 阶段确认
- 对照实验用 001 既有全历史信号产物，不重算信号
