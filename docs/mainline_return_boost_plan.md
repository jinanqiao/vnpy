# 主线策略收益提升改造方案（008 提案）

**目标**：以年化收益为第一优先级，回撤和换手作为约束项（回撤不深于 -25%、
年换手不超过 8 倍），在现有月频框架上做一轮系统性改造。
**基线**：月频 60/20/60 + MA60 调仓日择时 + 无信号清仓 = 年化 +0.52%、回撤 -22.8%。
**已实现的最大单项**：逐日择时 MA120（007）= 年化 +9.76%、回撤 -16.7%（样本内）。

---

## 一、证据回顾（全部检验报告在 outputs/factor_checks/）

| 结论 | 证据 | 对改造的含义 |
|---|---|---|
| 择时信号对策略自身收益区分度高，MA120 最好 | IC +0.083（MA120）> +0.054（MA60） | 风控是最大的收益杠杆，优先做 |
| 择时只在调仓日检查有 23% 滞后暴露 | 弱市仍持仓 105/461 天，拖累 -9.4% | 已由 007 修复（逐日离场） |
| 逐日离场 + 月度进场不对称，踏空反弹 | 007 验收：MA60 逐日反而更差 | 对称的逐日再入场是下一个确定性改进 |
| 三个选股因子 2021-2025 IC 一致为负 | rs -0.06 / vol -0.05（显著），nh 弱正 | 打分方向要改，但注意 ↓ |
| **2026 年因子方向已翻正** | rs +0.015 / nh +0.054 / vol +0.002 | **纯反转会在 2026 亏钱，必须留样本外验证** |
| nh（距新高）是唯一稳健偏正的因子 | 过滤池周频 IC +0.016，分层单调 | 加权向 nh 倾斜比全盘反转更稳 |
| 行业动量选行业无效，行业层价值在状态开关 | 行业 IC ≈ 0，四组对照现状最优 | 行业层小改（新鲜度），不大动 |
| 老主线（连任 ≥2 期）个股下期收益转负 | 004 分析：第 4 周以上 -0.55%/周 | 新鲜度过滤值得在月频重测 |
| 止损全参数负贡献 | 5%~25% 六档扫描 | 保持关闭，不再投入 |

## 二、改造清单（按预期年化贡献排序）

### P0 风控/择时（预期贡献最大、证据最强）

1. **逐日择时 MA120 设为推荐配置**（已实现，样本内 +9.2pp 年化）。
2. **对称化：逐日再入场**。当前弱市次日清仓、但要等下一个调仓日才回场；
   改成"基准收复均线次日，按最近一期信号清单重新建仓"。
   预期：吃回每段下跌结束后的头几天反弹；风险：均线附近来回进出增加成本，
   需配 1~2 天确认或缓冲带（如收复均线 +1% 才回场）。新增开关 `timing_reentry_enabled`。
3. **择时基准换成风格匹配指数**：用全 A 等权指数（数据湖可直接构建）替代沪深300，
   持仓是中小盘强势股，基准错配是已知问题。新增 `benchmark_symbol` 支持 `EW_ALL_A`。
4. **分级仓位（可选）**：收盘在 MA120 上方满仓、MA60~MA120 之间半仓、下方空仓。
   预期：平滑鞭打；风险：半仓状态拖低牛市年化，与"年化优先"目标可能冲突，放最后。

### P1 选股打分（方向调整，必须过样本外关）

5. **三组打分变体对照**（信号层只需改 `score_weights`，已支持负权重需小改）：
   - A 证据对齐版：`(-0.40, +0.35, -0.25)` —— rs/vol 反用（它们显著为负），nh 保持正向；
   - B 纯 nh 版：`(0, 1, 0)` —— 只按距新高排序，放弃另外两个因子；
   - C 全反转版：`(-0.40, -0.35, -0.25)` —— 你要求的"反着用"，作为对照组进实验；
   - 现状 `(+0.40, +0.35, +0.25)` 作基线。
   实现：`rank_and_score` 允许负权重（排名反向），配置校验放开。
6. **候选池放宽实验**：五项硬过滤在池级贡献为负（年化约 -11%），
   试"只保留可交易 + 上市满一年"的宽过滤变体（均线/乖离/距新高过滤关闭），
   让打分因子在更大的池子里工作。新增开关 `trend_filters_enabled`。

### P2 行业层（小改）

7. **主线新鲜度月频重测**：`max_industry_streak=1`（只买新晋主线）配合
   逐日择时 MA120 重跑——004 时它的裸信号更好但被旧风控掩盖，值得在新风控下复验。
8. **申万 regime 状态开关复测**：sw1_regime 在旧风控下接近基线（-0.05%），
   配逐日 MA120 后可能反超，一组回测的成本顺手验证。

## 三、实验纪律（防止"年化最高 = 过拟合最深"）

- **样本切分**：2022-08 ~ 2025-06 为选择期，2025-07 ~ 2026-07 为验证期。
  所有变体先在选择期排序，只把前 3 名放到验证期看是否仍然为正、排序是否稳定。
  **验证期数字只看一次**，不回头改参数再看第二次。
- **实验矩阵封顶**：P0 组合 × P1 打分 4 变体 × P2 两项 ≤ 24 组，一次跑完不加塞；
  中途冒出的新想法记到下一轮，不进本轮矩阵。
- **评价顺序**：验证期年化 → 全样本回撤 ≤ -25% → 年换手 ≤ 8。
- **申报口径**：最终推荐配置必须同时给出选择期和验证期两段数字，
  以及与基线的逐年对比；只报全样本数字视为无效。

## 四、执行顺序与工作量

| 步骤 | 内容 | 改动 | 预估 |
|---|---|---|---|
| 1 | 逐日再入场 + 全 A 等权基准（P0-2/3） | mainline_backtest 2 个开关 + 测试 | 半天 |
| 2 | 负权重打分 + 宽过滤开关（P1-5/6） | mainline 小改 + 测试 | 半天 |

| 4 | 跑全矩阵 + 出对比报告 + 定推荐配置 | 计算 | 1~2 小时 |

## 五、必须说清的红线

1. "IC 为负所以反着用"在逻辑上等价于"把 2021-2025 的反转效应当成永恒规律"，
   而 2026 年它已经翻转。C 组（全反转）大概率在选择期排名很高、验证期露馅——
   这正是设计样本外验证的原因。如果它两段都赢，才值得信。
2. 007 的 MA120 本身就有样本内择优嫌疑，本轮把它放进同一套切分里重新过一遍。
3. 预期管理：多重比较下，本轮"最优组合"的样本内年化几乎必然超过 +10%，
   但真实可信的量级要打对折以上折扣；回测不代表未来收益，不构成投资建议。
